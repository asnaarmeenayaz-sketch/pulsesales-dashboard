# PulseSales — Executive Sales & Performance Dashboard

PulseSales is an interactive executive sales dashboard designed to monitor revenue, sales pipeline, deals, team performance, and regional sales insights through a clean and modern interface.

## Features

- Executive revenue and performance overview
- Sales pipeline and deal management
- Team performance leaderboard
- Regional and source attribution
- Revenue and pipeline visualizations
- Live activity feed
- New deal creation
- CSV and JSON data export
- Currency selection
- Responsive dashboard interface

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
